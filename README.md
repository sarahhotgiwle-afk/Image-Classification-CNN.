\# Cat vs Dog Image Classification



\## Project Overview

This project uses a Convolutional Neural Network (CNN) to classify images as cats or dogs.



\## Technologies

\- Python

\- TensorFlow and Keras

\- NumPy



\- Matplotlib

\- Pillow

\- JupyterLab



\## Model Performance

\- Best validation accuracy: 83.07%

\- Final validation accuracy: 81.43%
